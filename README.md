Сайт уже готов и доступен по ссылке: [https://kelf2009-801.github.io/shalun2/](https://kelf2009-801.github.io/shalun2/)

## Технические детали

- **Технологии**: Чистый HTML, CSS, JavaScript
- **Хостинг**: GitHub Pages
- **Деплой**: Автоматически при пуш в ветку gh-pages

## Как обновить сайт

1. Отредактируйте файл `gh-pages/index.html`
2. Сохраните изменения
3. Сделайте коммит и пуш в ветку gh-pages

```bash
git add gh-pages/index.html
git commit -m "Update landing page"
git push origin gh-pages
```

GitHub Pages автоматически обновит сайт в течение нескольких минут.
